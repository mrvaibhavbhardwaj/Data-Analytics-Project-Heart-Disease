# ❤️ Heart Disease Analysis Dashboard

An interactive **Heart Disease Analysis Dashboard** built to analyze patient health data and uncover key insights related to heart disease risk factors, demographics, and medical indicators. This project provides comprehensive visual analytics using charts, KPIs, filters, and statistical analysis to support healthcare decision-making.

---

## 📌 Project Overview

This dashboard analyzes heart disease patient data and presents meaningful insights through interactive visualizations. It helps identify patterns between heart disease and factors such as:

* Age
* Gender
* Blood Pressure
* Cholesterol Levels
* Chest Pain Types
* Exercise-Induced Angina
* ECG Results
* Heart Rate
* Thallium Stress Test Results

The dashboard is designed for healthcare analytics, data visualization practice, and business intelligence learning.

---

## 📊 Dashboard Features

### 🔹 KPI Metrics

* Average Patient Age
* Total Patient Count
* Average Resting Blood Pressure
* Average Serum Cholesterol
* Average Maximum Heart Rate Achieved
* Heart Disease Rate

### 🔹 Visual Analysis

* Heart Disease Distribution
* Chest Pain Type Analysis
* Gender-wise Disease Comparison
* Blood Pressure Category Insights
* Cholesterol Level Analysis
* Exercise-Induced Angina Trends
* ECG and Thallium Stress Test Analysis
* Age vs Heart Disease Rate
* Multi-variable Statistical Comparisons

### 🔹 Interactive Filters

Users can filter dashboard data by:

* Sex
* Blood Pressure Category
* Chest Pain Type
* Cholesterol Level Category
* Exercise-Induced Angina
* Presence of Heart Disease
* Multiple Vessel Disease
* ECG Results
* Thallium Stress Test

## 📈 Key Insights

* Male patients showed a higher heart disease rate compared to females.
* Asymptomatic chest pain cases had a strong correlation with heart disease.
* High cholesterol and hypertension categories showed increased disease presence.
* Heart disease rates increased significantly with age.
* Exercise-induced angina and abnormal stress test results were major indicators.
